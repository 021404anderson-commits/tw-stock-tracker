# 台股每日追蹤系統

每個交易日自動追蹤台股指數與關注個股，並整理法說會、供應鏈位置與產品比重。

網頁：https://021404anderson-commits.github.io/tw-stock-tracker/

## 這個系統怎麼運作

| 項目 | 來源 | 更新方式 |
|---|---|---|
| 加權指數、櫃買指數、個股開高低收、成交量與成交金額、三大法人買賣超 | 證交所、櫃買中心公開資料 | GitHub Actions 每個交易日 15:37、18:07、21:07（台北時間）自動執行 `fetch.py` |
| 法說會日期、產品比重 | 財經媒體的法說會整理，附來源連結 | Claude 排程任務每週六 08:43 檢查並更新 `fundamentals.json` |
| 供應鏈位置、關注清單 | 人工設定 | 修改 `watchlist.json` |

## 族群強弱排名

網頁上方依 `watchlist.json` 的產業分組，把各族群由強到弱排序。**這是已發生的數據，不是漲跌預測。**

| 指標 | 算法 | 何時開始納入 |
|---|---|---|
| 當日漲跌 | 族群內個股漲跌幅的簡單平均 | 立即 |
| 法人買賣超占成交比重 | 三大法人買賣超股數 × 收盤價（估算金額）÷ 當日成交金額 | 立即 |
| 近 5 日報酬 | 個股 5 個交易日漲跌幅的平均 | 累積滿 6 個交易日 |
| 量能變化 | 最新一日成交金額 ÷ 之前最多 20 日的平均 | 累積滿 4 個交易日 |

每個指標在族群之間排名次，再把名次平均成綜合排名。族群只計入關注清單內的個股，所以只有 1 檔的族群其實就是那一檔的表現。三大法人資料通常比收盤價晚公布，標題會標出價格與法人各自的資料日期。

## 網頁搜尋

網頁上方的搜尋方塊可以輸入：

- 公司名稱或股票代號（例：`台積`、`2330`）
- 產業、供應鏈或產品關鍵字（例：`記憶體`、`伺服器`、`CoWoS`）
- 法說會日期（例：`11/12`、`11月12日`、`2026-10-29`，或只打 `11月` 看整個月）

多個關鍵字用空白隔開，會找同時符合的個股。搜尋只在瀏覽器裡比對已載入的資料，不會另外連網。

## 檔案說明

- `watchlist.json`：關注的指數與個股（代號、名稱、上市 `twse`／上櫃 `tpex`、產業分組、供應鏈位置）
- `fundamentals.json`：每檔的法說會與產品比重
- `fetch.py`：抓取官方行情的程式，只用 Python 內建模組
- `data/latest.json`：最新一次抓到的行情
- `data/history.json`：累積的每日收盤（約保留一年），用來畫走勢線
- `data/flow.json`：累積的每日成交金額與三大法人買賣超（約保留一年），用來算族群排名
- `index.html`：網頁
- `.github/workflows/daily.yml`：每日自動執行的排程

## 常見調整

- **增減個股**：在 `watchlist.json` 的 `stocks` 加一筆或刪一筆，下次自動更新就會生效。
- **手動立刻更新**：到 GitHub 的 Actions 頁面，選「每日更新」，按 Run workflow。
- **資料沒更新**：網頁上方若出現紅色提示，代表有項目抓不到；到 Actions 頁面看最近一次執行的紀錄。

行情為官方盤後資料，非即時報價。本系統僅供研究參考，非投資建議。
